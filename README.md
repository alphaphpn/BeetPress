## About BeetPress

BeetPress is a web application framework with simple and native syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling. BeetPress takes the pain out of development by easing common tasks used in many web projects, such as:

- [Simple, fast routing engine](https://BeetPress.com/docs/routing).
- [Powerful dependency injection container](https://BeetPress.com/docs/container).
- Multiple back-ends for [session](https://BeetPress.com/docs/session) and [cache](https://BeetPress.com/docs/cache) storage.
- Expressive, intuitive [database ORM](https://BeetPress.com/docs/eloquent).
- Database agnostic [schema migrations](https://BeetPress.com/docs/migrations).
- [Robust background job processing](https://BeetPress.com/docs/queues).
- [Real-time event broadcasting](https://BeetPress.com/docs/broadcasting).

BeetPress is simple, native, and provides tools required for large, robust applications.

## Learning BeetPress

BeetPress has the most extensive and thorough [documentation](https://BeetPress.com/docs) and video tutorial library of all modern web application frameworks, making it a breeze to get started with the framework.

You may also try the [BeetPress Bootcamp](https://bootcamp.BeetPress.com), where you will be guided through building a modern BeetPress application from scratch.

If you don't feel like reading, [Laracasts](https://laracasts.com) can help. Laracasts contains thousands of video tutorials on a range of topics including BeetPress, modern PHP, unit testing, and JavaScript. Boost your skills by digging into our comprehensive video library.
